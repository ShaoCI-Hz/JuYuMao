# 局域猫 · 歌曲功能升级与入口改造方案

> 状态：已确认方向，分阶段实施
> 参考：SALT PLAYER（椒盐音乐）功能体系
> 日期：2026-08-14

## 一、现状盘点

### 已有功能分布（4 个层级，分散）

| 层级 | 入口 | 功能 |
|---|---|---|
| 列表行 | 点按=播放；加号=加歌单；竖三点=详情 | 详情弹窗只读 |
| 播放页 | 底栏：歌词 / 队列 / 收藏 / 更多 | "更多"只弹"添加到歌单"；倍速在进度条旁 |
| 首页宫格 | 均衡器 / 定时关闭 / 队列 / 歌单 / 报告 / 缓存管理 | **缓存管理 onClick 为空实现（bug）** |
| 独立页 | 搜索 / 均衡器 / 缓存 / 报告 / 歌单 / SMB | 均衡器 10 段+低音/虚拟/响度；报告累计/TOP10 |

### 核心问题

1. **详情弹窗是死胡同**：只读展示，无法从详情触发任何操作
2. **播放页"更多"单薄**：只挂一个加歌单动作
3. **无统一歌曲操作菜单**：同一动作散在加号/三点/播放页更多，能力不一致
4. **长按交互缺失**：CacheScreen 文案写着"长按 NAS 下载"，SongListItem 无 onLongClick（半成品）
5. **数据有、入口无**：`BrowseViewModel.albumNames/artistNames/genreNames/loadDimensionSongs` 代码保留但入口被移除；`addedAt`（最近添加）、`playCount`（播放最多）字段有但无视图
6. **单曲功能偏少**：无下一首播放/稍后播放（PlaybackQueue 无插队）、列表行无收藏快捷、NAS 下载入口缺失、无均衡器预设、队列不能存为歌单

## 二、入口改造方案（统一歌曲操作模型）

**核心**：所有歌曲操作收敛到聚合底部弹层 `SongActionSheet`（Miuix `OverlayBottomSheet`），四个触发点共用：

```
SongActionSheet(song, ...)
  ├─ 列表行「竖三点」
  ├─ 列表行「长按」（补 onLongClick）
  ├─ 播放页底栏「更多」（替换原"只弹加歌单"）
  └─ 详情弹窗底部操作栏（播放/收藏/加歌单/下一首）
```

菜单项（按来源/状态动态显示）：

| 操作 | 说明 |
|---|---|
| ▶ 播放 | 立即播放该歌 |
| ⏭ 下一首播放 | 插到队列当前+1 位置（新能力） |
| 📥 稍后播放 | 追加到队尾（新能力） |
| ♥ 收藏 / 取消收藏 | 列表行另加快捷按钮 |
| ➕ 添加到歌单 | 保留 |
| ⬇ 下载到本地 | 仅 NAS 歌（补半成品） |
| ℹ 歌曲详情 | 信息+操作弹窗 |
| ⏩ 倍速 | 播放页上下文专用 |

**详情弹窗改造**：信息键值区保留，底部加操作栏（播放/收藏/加歌单/下一首播放）。

**修复**：首页"缓存管理"宫格接真实导航。
