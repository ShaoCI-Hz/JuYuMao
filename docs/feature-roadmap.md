## 三、升级点归纳（按局域猫定位筛选，分优先级）

### P0 — 高价值、与"私有音乐库"定位最契合、工作量可控

1. **音效预设扩充**（对标网易云/QQ音乐）——现有内置 6 套基础上加：3D 环绕、超重低音、人声、古风、民谣、摇滚现场等；预设可选配低音/虚拟器联动
2. **歌词增强**——
   - 逐字/卡拉OK 滚动（对标 QQ/网易云，需按字符时间切分，LRC 有逐字时间可做）
   - 歌词翻译（外文歌，需词库，可做内置常见词或留空）
   - 歌词海报分享（歌词 + 封面 + 主题色生成图片，分享到系统）
3. **智能歌单 Smart Playlist**（对标开源播放器/Apple 智能列表）——按条件自动生成：评分 ≥N、播放次数 ≥N、最近添加 N 天、流派、歌手、本地/NAS；自动刷新
4. **批量多选操作**（对标网易云/QQ音乐）——列表长按进入多选模式：批量加歌单/收藏/评分/删除/下载
5. **专辑/艺术家详情页**——维度浏览已有，但缺详情页：专辑封面大图 + 曲目列表 + 播放全部 + 艺术家同专辑；艺术家页聚合
6. **手势增强**（对标汽水音乐/Spotify）——播放页左右滑动切歌、双击暂停/播放、滑动歌词调节进度

### P1 — 中价值，需一定工程量

7. **在线歌词下载**——现有仅内嵌/SMB，可加 LRC 在线搜索（需歌词源，注意版权/离线原则可做成可开关）
8. **ReplayGain 音量归一化**（对标开源播放器高级特性）——扫描时读取/计算响度，播放时统一音量，解决不同专辑音量跳变
9. **相似歌曲推荐（轻量）**——基于播放历史：同艺术家/同流派/同标签的"猜你喜欢"区块（无需后端）
10. **报告增强**——现有累计/TOP10 基础上加：年度曲线、最爱歌曲/艺术家、播放时长分布、深夜听歌统计（对标 Wrapped）
11. **睡眠定时增强**——现有 15-90 分钟静音，加"音量渐弱"（最后 30s 淡出）与"播放完当前曲后停止"
12. **通知栏/锁屏控制增强**——MediaSession 已有基础，加进度拖动、歌词显示、收藏快捷（在通知栏）
13. **小组件升级**——现有 widget 加多尺寸/歌词显示/播放控制（参考 Retro Music）
14. **主题扩展**——现有 Dark/Light/System 加"自定义强调色"（Miuix ColorScheme 可自定义 primary）

### P2 — 远期/与定位冲突或成本高

15. **音乐云盘/跨设备同步**——本地音乐上传 NAS / 播放进度跨设备同步（局域猫天然适合，但需账号体系，成本高）
16. **听歌识曲**——需音频指纹 SDK/后端
17. **在线曲库/电台/播客/社交评论**——与"完全私有本地"定位冲突，不推荐
18. **AI 功能**（AI 歌单/电台）——依赖在线服务，本地化成本极高

## 四、建议落地顺序

1. 先做 P0-1（音效预设扩充）+ P0-2（歌词增强：逐字 + 海报分享）——用户感知最强、改动集中
2. P0-4 批量多选 + P0-5 专辑/艺术家详情页——补齐浏览与操作闭环
3. P0-3 智能歌单 + P0-6 手势
4. P1 按需推进（在线歌词需先确认歌词源版权策略）
